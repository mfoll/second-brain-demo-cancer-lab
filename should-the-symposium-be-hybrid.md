# Should The Symposium Be Hybrid?

Should the [[tumour-evolution-symposium-2026]] offer remote participation, and if so for which parts?

## Current Answer

> [!success]
> In person only, with the keynote streamed; decided on 2026-02-18 and kept after the venue contract showed a second streamed room would add cost.

## Reasoning

- For hybrid ([[oluwaseun-adebayo]]): lower travel costs and carbon, access for people without travel funding, more early-career reach.
- Against (Ines): previous hybrid meetings had passive remote audiences and stilted questions; streaming every session needs a technician per room; the poster session, which is the main early-career opportunity, does not work remotely.
- Compromise: the keynote is streamed publicly, and slides are shared afterwards where speakers consent.

## Afterthought

Oluwaseun's concern about travel funding proved real for three invited speakers ([[symposium-speaker-list]]). Revisit the format if the symposium runs again in 2028.
