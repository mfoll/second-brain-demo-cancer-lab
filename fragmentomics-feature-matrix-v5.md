# Fragmentomics Feature Matrix v5

The current feature matrix for the [[fragmentomics-classifier|fragmentomics classifier]], generated with FinaleToolkit inside the pipeline container on Halyard and frozen on 2026-04-20.

## Key Details

- 1,402 St Aldric samples plus 32 bridging libraries.
- Columns: sample ID, patient ID, time point, extraction lot, extraction batch, sequencing run, 66 length bins, 541 window ratios, 4 summary length features, 256 end-motif frequencies, motif diversity score.
- Raw and bridging-corrected length features both stored; the model uses corrected values.
- Generated by pipeline release `varga-cfdna` 1.2 with container digest recorded in the manifest.

## Version History

- v3 (2025-11): our own scripts, used in the submitted manuscript.
- v4 (2026-01): FinaleToolkit, no batch columns.
- v5 (2026-04): batch columns, bridging correction, randomised re-extractions included.
