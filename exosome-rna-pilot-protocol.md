# Exosome RNA Pilot Protocol

Bench protocol for the [[exosome-rna-pilot]], written by [[elias-moreau]] on 2025-02-12: plasma thawing, vesicle isolation with two commercial kits in parallel, RNA extraction, small and long RNA library preparation.

## Key Details

- Input 4 ml plasma, double-spun; processing within one day of thawing.
- Spike-in RNA controls added before isolation to measure recovery.
- Kept because the plasma handling steps were reused for the methylation panel pilot runs.
