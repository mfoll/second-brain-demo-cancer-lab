# How Much Of The Aurora Budget Goes To Proteomics?

How much of the 2.41 M EUR Aurora request should fund work package 2.3, plasma proteomics in Marta Kowalczyk's group?

## Current State

Provisional figure from the [[aurora-budget-review-2026-10-15]]: 380 k EUR, covering a 0.5 FTE postdoc for five years and proteomics as a service line for one post-surgery time point per patient. Marta asks for 450 k EUR to add a second time point at six months, which would let the work package test whether protein changes precede imaging relapse rather than only whether a single draw is informative.

## Options

- 380 k EUR, one time point: fits with Brightwater included; weaker longitudinal claim.
- 450 k EUR, two time points: stronger science, but only fits if Brightwater stays out of aim 2.
- 450 k EUR with a smaller sequencing line: Dmitri argues this would underpower the main MRD analysis.

## Decision Needed By

2026-11-10, when [[chloe-armitage]] freezes the [[aurora-budget-sheet]]. Depends on [[should-aurora-include-brightwater-as-second-mrd-site]].
