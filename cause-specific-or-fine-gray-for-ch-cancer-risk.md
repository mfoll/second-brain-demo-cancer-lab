# Cause-specific or Fine-Gray for CH cancer risk?

## Question

In the CH subcohort, 512 participants died of non-cancer causes by 2025, and CH is associated with cardiovascular death. Which competing-risk model should carry the main result?

## Current thinking

The [[ch-cancer-risk-analysis-plan]] makes cause-specific hazards the main estimate, because the question is aetiological: does CH change the rate of solid cancer among people still alive and cancer-free? Cumulative incidence curves by CH status show absolute risk. A Fine-Gray model is reported only as a description ([[austin-2017-fine-gray-reporting]], [[austin-2016-competing-risks-introduction]]).

What is still open: [[mei-lin-zhou]] wants the absolute-risk message (how many extra cancers by age 80 in CH carriers) in the abstract, which needs cumulative incidence, and CH raises non-cancer death too, so the cumulative incidence difference could be smaller than the hazard ratio suggests. [[lucas-brandt]] will show both before deciding what goes in the abstract.

## What would answer it

A side-by-side table with the 2025 follow-up. If the two tell the same story, keep the plan; if not, report both with an explanation.
