# Summer Internships 2026

Two MSc interns hosted from June to August 2026: [[noor-haddad]] and [[kofi-mensah]]. The Project ran from the call for topics in March to the end of the internships on 2026-08-28.

## Outcome

Reached: both interns completed a bounded project, gave a final talk on 2026-08-26 and handed over code and a short report.

## Current State

- Completed. Noor's panel-of-normals prototype for clonal hematopoiesis filtering is being continued by [[hannah-lindqvist]] inside the [[clonal-hematopoiesis-filter]] Project; it is one input to the open question on matched buffy coat sequencing.
- Kofi's low-count spot simulation became a supplementary experiment in the [[deconvolution-benchmark]]; [[kenji-mori]] will cite it in the preprint.
- Both reports and code are archived in the group repository under `internships/2026/`.

## Scope and Boundaries

Recruitment, supervision arrangements and the internship deliverables. The science continues in the receiving Projects. Interns worked on synthetic or already de-identified data inside governed storage; neither had access to linked registry data.

## Working Context

Topics were agreed in March: one per intern, each with a daily supervisor from the group and Ines as formal supervisor. Noor was supervised by Hannah with [[dmitri-halvorsen]] as second contact; Kofi by Kenji. Both topics were written up as one-page descriptions ([[intern-project-panel-of-normals-ch]], [[intern-project-low-count-spot-simulation]]). [[priya-raman]] handled contracts, badges and Halyard accounts with [[yara-castellanos]] for the data access training.

The lesson repeated from 2025: an intern project works when the question fits in ten weeks and has a known answer shape. That is now an Opinion: [[interns-need-one-bounded-question]].
