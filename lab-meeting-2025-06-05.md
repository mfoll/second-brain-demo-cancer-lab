# Lab Meeting 2025-06-05

Chair Ines Varga, notes [[kenji-mori]]. Thirteen present.

## Decisions

- **Exosome RNA pilot stops.** The in silico test showed the methylation panel captures the same tumour signal with far more input DNA available. The [[exosome-rna-pilot]] is superseded by the [[methylation-panel-design]] and closes on 2025-06-30. Remaining exosome samples go back to the freezer, not discarded.
- **CH filter.** [[hannah-lindqvist]] started the [[clonal-hematopoiesis-filter]] on 2025-06-02. Agreed scope: a filter that works with and without matched buffy coat, so it can be applied to samples where no buffy coat was banked.
- **Low-VAF benchmark.** [[low-vaf-caller-benchmark]] running since 2025-05-05 with spike-in dilutions. Decision: use only in-house dilutions for now and report them as such.
- **DMP approved.** The data governance board approved the [[group-data-management-plan]] on 2025-05-27. Two conditions, both owned by [[yara-castellanos]].
