# Course Teaching Materials Repository

## Summary

The group's repository for the cancer genomics course: notebooks, simulated datasets, slides and the syllabus, one branch per edition. Tagged `edition-2026` on 2026-05-25.

## Key Details

- Simulated cfDNA and case-control datasets with generation scripts, so no real patient data are ever in the repository.
- Environment defined in a container recipe maintained by [[tobias-wren]]; moving to an Apptainer image for Halyard in 2027.
- Guest lecture slides are not in the public mirror, at the lecturers' request.
- Private `feedback/` folder, not mirrored.

## Source Location

Institute GitLab, `teaching/cancer-genomics-course` (root key `group_gitlab`), public mirror without `feedback/` and guest slides.
