# Lab Onboarding Checklist

The checklist [[priya-raman]] keeps for each new member, a spreadsheet with one tab per person. Revised 2026-10-12 for [[owen-mcallister]]'s arrival, adding Halyard GPU membership and the code review rota.

## Summary

Forty-one items in four blocks: before arrival (accounts, desk, data protection training, buddy), first day, first week, first month. Each item has an owner and a done date. The procedure that uses it is [[onboard-a-new-lab-member]].

## Key Details

- Before arrival: institute ID, email, GitLab, Halyard account request (needs training certificate), data access through [[yara-castellanos]], buddy named.
- First week: read the [[lab-handbook]], [[halyard-user-guide]] and [[group-data-management-plan]]; run the cfDNA test profile; meet each project lead for 20 minutes.
- First month: first lab meeting presentation (10 minutes, "what I did before and what I want to do here"), added to [[lab-meeting-rota-2026]] and the review rota in [[who-owns-what]]; 30-day check-in with Ines.

## Caveats

Wet-lab items (lab safety induction, freezer access) are only relevant for [[elias-moreau]]'s side and are in a separate tab.
