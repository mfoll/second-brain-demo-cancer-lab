# Introducing the FAIR Principles for research software.

Barker M et al., Scientific Data, 2022.

## Summary

Presents the FAIR Principles for Research Software (FAIR4RS), adapted from the FAIR data principles by a community working group, with the context for each principle and examples of how organisations have implemented them.

## Why It Matters

[[yara-castellanos]] wants the next revision of the [[lab-data-management-plan]] to cover software as well as data, and this is her reference. The practical outcome so far: every group repository now has a licence, a citation file and a persistent identifier on release.

## Caveats

Principles, not a checklist; FAIR software can still be unmaintained. [[sonabend-2024-fair-use4os]] tries to close that gap.
