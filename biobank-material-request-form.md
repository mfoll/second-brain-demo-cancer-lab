# Biobank Material Request Form

The form every project uses to request samples from the [[corvane-biobank]]. Version 5, in use since 2024. First used by the group for the [[case-control-sample-selection]] request in March 2025.

## What It Asks For

- Project, ethics approval reference and data access approval reference.
- Sample list by study ID, material type and volume; justification for more than one aliquot per participant.
- Whether any requested sample is a last aliquot (the form flags these automatically against the LIMS).
- Planned assays and expected consumption; return or destruction of unused material.
- Data to be returned with samples (draw date, processing delay, thaw count).

## Practical Notes

[[paolo-ferrante]] reviews within two weeks; Northvale requests then go to the board. The 2025 case-control request flagged 141 last-aliquot samples, of which the board approved release for cases only (54) and asked for replacement controls for the rest. Plan for that when sampling controls.
