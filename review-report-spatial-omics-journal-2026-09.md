# Review Report For Spatial Omics Journal, September 2026

Report on a manuscript proposing a new cell-type deconvolution method for spatial transcriptomics. Generic record only.

## Main Points Raised

- Benchmarks used only high-count spots; Ines asked for results stratified by spot total counts, because the group's own [[deconvolution-benchmark]] found that some methods fail silently on low-count spots.
- Requested that failure cases be shown, not just averages.
- Code was available and ran; Ines thanked the authors for that explicitly.

## Conflict Check

The method competes with those in [[kenji-mori]]'s benchmark, which is not yet public. Ines declared this to the editor before accepting; the editor kept her as reviewer and she did not mention or share the benchmark results. Kenji was not involved.

## Recommendation

Minor revision.
